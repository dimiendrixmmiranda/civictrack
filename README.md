## 📌 Sobre o Projeto

O **CivicTrack** é uma plataforma inteligente desenvolvida para o registro, análise e priorização de problemas urbanos, como falhas de infraestrutura, iluminação pública e gestão de resíduos.

O sistema vai além de um simples cadastro, aplicando uma abordagem interdisciplinar baseada em critérios sociais, econômicos, técnicos e legais, auxiliando na tomada de decisão de forma estruturada.

---

## 🎯 Objetivo

Criar uma solução tecnológica capaz de:

* Centralizar o registro de problemas urbanos
* Classificar ocorrências com base em risco e impacto
* Estimar custos de resolução
* Priorizar demandas de forma inteligente
* Apoiar decisões com base em múltiplos critérios

---

Este projeto foi desenvolvido com base nas disciplinas do curso de Engenharia da Computação, integrando conhecimentos teóricos em uma aplicação prática.

Uso de critérios técnicos para análise de problemas.

## ⚙️ Funcionalidades

* Cadastro de problemas urbanos
* Classificação por categoria (buraco, iluminação, lixo, etc.)
* Avaliação de risco
* Estimativa de custo de resolução
* Priorização automática
* Listagem e acompanhamento de ocorrências

## ▶️ Como Executar

```bash
# Clonar o projeto
git clone https://github.com/seu-usuario/civictrack.git

# Entrar na pasta
cd civictrack

# Instalar dependências
npm install

# Rodar o projeto
npm run dev
```

Acesse:

```
http://localhost:3000
```
